### ? Phase 12.5: Options to Configuration Migration (Complete)
**Completed:** 2025-01-15

#### Objective
Remove the legacy `Options` class that was mocking WebUI settings and migrate to `IConfiguration` for output paths.

#### Analysis

The `Options` class (`BlazorWebApp.Models.Options`) contained:
- **WebUI-era properties (removed)**: ClipSkip, ENSD, EtaDdim, SDVae, grid settings, etc.
- **Still needed**: Output directories, filename patterns, samples format, save flag

These were being generated by `ComfyUIService.GenerateOptions()` which created hardcoded defaults - a mock of WebUI's `/sdapi/v1/options` endpoint that doesn't exist in ComfyUI.

#### Changes Made

**1. Created `OutputPathsOptions` model** ?
- New configuration class at `BlazorWebApp/Models/OutputPathsOptions.cs`
- Maps to `OutputPaths` section in `appsettings.json`
- Contains: `Txt2ImgSamples`, `Img2ImgSamples`, `Img2VidSamples`, `Extras`, `DirectoryPattern`, `FilenamePattern`, `SamplesFormat`, `SaveSamples`

**2. Updated `appsettings.json`** ?
- Added `OutputPaths` section with all path configuration
- Centralizes output configuration in one place

**3. Updated `IBackendService`** ?
- Removed `Options` property
- Added `OutputPaths` property (type `OutputPathsOptions`)
- Added `GetOutputPath(Outdir outdir)` method
- Removed `GetOptions()` and `PostOptions()` methods

**4. Updated `BackendService`** ?
- Constructor now takes `IConfiguration`
- Loads `OutputPathsOptions` from configuration on construction
- Implements `GetOutputPath()` for calculating full output paths
- Removed `GetOptions()`, `PostOptions()` methods

**5. Updated `IComfyUIService` and `ComfyUIService`** ?
- Removed `GenerateOptions()` method entirely
- Options no longer needed from ComfyUI API

**6. Updated `ManagerService`** ?
- Removed `GetOptions()` and `PostOptions()` methods
- Updated `GetCurrentSaveFolder()` to use `_backend.GetOutputPath()`
- Updated `ConvertPathTag()` to not reference Options
- Removed `[model_hash]` tag (not used in ComfyUI)

**7. Updated `ImageService`** ?
- Uses `_backend.OutputPaths.SaveSamples` instead of `_backend.Options?.SamplesSave`
- Uses `_backend.OutputPaths.SamplesFormat` instead of `_backend.Options.SamplesFormat`
- Uses `_backend.OutputPaths.FilenamePattern` instead of `_backend.Options.FilenamePatternSamples`
- Uses `_backend.GetOutputPath()` for base paths

**8. Updated `GenerateFormTxt2Img.razor`** ?
- Removed unused `_options` field that was referencing `Backend.Options`

**9. Updated Tests** ?
- `BackendServiceTests` now uses mock `IConfiguration`
- Removed tests for `GetOptions()`/`PostOptions()` (no longer exist)
- Added tests for `OutputPaths` and `GetOutputPath()`
- `MockComfyUIServiceBuilder` no longer has `WithOptions()` or `GenerateOptions` setup

- `IBackendService.Options` removed - use `IBackendService.OutputPaths` instead
- `IBackendService.GetOptions()` removed - no replacement needed (config is loaded on startup)

- `IComfyUIService.GenerateOptions()` removed - no replacement needed

### DI Registration Reference

#### Interface-Only (Clean Pattern)
```csharp
builder.Services.AddSingleton<IEventService, EventService>();
builder.Services.AddSingleton<ISettingsService, SettingsService>();
builder.Services.AddSingleton<IIOService, IOService>();
builder.Services.AddSingleton<IStateService, StateService>();
builder.Services.AddSingleton<IBackendService, BackendService>();
builder.Services.AddSingleton<IModelService, ModelService>();
builder.Services.AddSingleton<IGalleryService, GalleryService>();
builder.Services.AddSingleton<ISessionService, SessionService>();
builder.Services.AddSingleton<IRouterService, RouterService>();
builder.Services.AddSingleton<IWorkflowService, WorkflowService>();
builder.Services.AddScoped<IAssetResolverService, AssetResolverService>();
```

#### Dual Registration (Required)
```csharp
// Components still inject concrete type
builder.Services.AddSingleton<DatabaseService>();
builder.Services.AddSingleton<IDatabaseService>(sp => sp.GetRequiredService<DatabaseService>());

// ProgressContainer subscribes to OnUpdate event
builder.Services.AddSingleton<ProgressService>();
builder.Services.AddSingleton<IProgressService>(sp => sp.GetRequiredService<ProgressService>());

// ComfyUIWebsocketService sets Progress directly
builder.Services.AddSingleton<ImageService>();
builder.Services.AddSingleton<IImageService>(sp => sp.GetRequiredService<ImageService>());
```
